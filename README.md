# hello-static

Статический сайт на чистом HTML + CSS + JS без сборщика и без зависимостей.
Файлы выкладываются на **GitHub Pages** как есть — ровно те, что лежат в
каталоге `public/`.

## Что на странице

| Блок | Содержимое |
|---|---|
| Шапка | логотип, навигация по разделам, переключатель темы |
| Герой | заголовок, описание, кнопки и команда `docker pull` с копированием |
| Числа | проекты, пайплайны, стеки, цели публикации |
| Консоль | анимация прогона CI: логи, прогресс-бар, часы, кнопка перезапуска |
| Возможности | четыре карточки: проверки, сборка, публикация, гейтинг |
| Счётчик | счётчик сборок с сохранением в `localStorage` |

## Интерактив

* **Тема.** Тёмная и светлая, выбор сохраняется в `localStorage`. Если
  пользователь ещё не выбирал тему, берётся системная настройка
  `prefers-color-scheme`.
* **Консоль сборки.** По нажатию «Проиграть снова» логи прокручиваются
  заново, прогресс-бар заполняется по мере вывода строк.
* **Копирование команды.** Кнопка рядом с командой кладёт текст в буфер
  обмена и подтверждает это подписью; для браузеров без Clipboard API есть
  запасной вариант через `execCommand`.
* **Счётчик.** Значение переживает перезагрузку страницы — оно лежит в
  `localStorage`, а не на сервере.
* **Появление блоков.** Секции проявляются при прокрутке через
  `IntersectionObserver`; активный раздел подсвечивается в навигации.
* **Доступность.** Учитывается `prefers-reduced-motion`: анимации
  отключаются, контент виден сразу.

## Что делает пайплайн

| Шаг | Что происходит |
|---|---|
| Проверка структуры | убедиться, что на месте `index.html`, `style.css`, `script.js`, `favicon.svg` и что они подключены |
| `configure-pages` | подготовить окружение Pages |
| `upload-pages-artifact` | загрузить папку `public/` как артефакт сайта |
| `deploy-pages` | опубликовать сайт |

Сборки нет вообще: GitHub Pages отдаёт файлы как есть.

## Структура

```
.
└── public/
    ├── index.html     # разметка страницы
    ├── style.css      # темы, сетка и компоненты
    ├── script.js      # тема, консоль, копирование, счётчик, скролл
    └── favicon.svg    # иконка вкладки
```

Все ссылки внутри страницы относительные (`./style.css`), поэтому сайт
одинаково работает и по пути `/`, и по пути `/hello-static/`.

## Локальный запуск

```bash
cd hello-static
python -m http.server 8000 --directory public
# открыть http://localhost:8000
```
